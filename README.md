-- This project presents an interactive HR Analytics Dashboard built using Tableau to analyze employee attrition, workforce demographics, job satisfaction, and departmental trends.

-- The goal of this project is to transform raw HR data into meaningful insights that help organizations make data-driven workforce decisions.

🎯 Business Problem
Employee attrition impacts productivity, hiring costs, and team stability.
This dashboard helps HR teams:
Monitor attrition rate
Identify high-risk departments
Analyze demographic trends
Understand job satisfaction patterns
Support workforce planning

📈 Key KPIs
Total Employees: 1,470
Attrition Count: 237
Attrition Rate: 16.12%
Active Employees: 1,233
Average Age: 37

🔍 Dashboard Insights
Sales department shows the highest attrition.
25–34 age group has the highest attrition volume.
Attrition is higher among male employees.
Life Sciences & Medical education fields show higher exits.
Job satisfaction levels vary significantly across roles.
